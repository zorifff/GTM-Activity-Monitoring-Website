# Anti-Slop Audit Report #001
**Date:** 2026-10-29  
**Scope:** Keseluruhan Halaman Monitoring (Dashboard, Detail Branch, Upload Activity, Control Panel, Modals, Layout)  
**Evaluator:** Antigravity AI Agent (Mode: `after`)  
**Design Dials:** ENERGY 1 (Calm B2B Telemetry) / RHYTHM 2 (Structured Hierarchy) / MOTION 1 (Essential Micro-transitions)

---

## Executive Summary
Audit menyeluruh dilakukan terhadap kode frontend (`gtm-monitor-frontend/src`) dengan menguji setiap komponen visual, layout, aksesibilitas, interaktivitas, dan copywriting terhadap standar anti-slop (Hard Gate, Purpose-Gate, dan Quality Locks).

Ditemukan **16 temuan** yang dikelompokkan berdasarkan prioritas aturan:
- **10 Temuan HIGH (Hard Gate)**: Pelanggaran absolut yang memengaruhi aksesibilitas (kontras, keyboard/Escape), integritas data (mock fallback), dan semantik HTML.
- **3 Temuan MEDIUM (Purpose-Gate)**: Penggunaan teknik dekorasi berlebih (glowing keyframe, glassmorphism tak terkontrol, reduced-motion).
- **3 Temuan LOW (Quality Locks)**: Konsistensi gaya (border radius pill berlebih, emoji dalam placeholder, konsistensi font token).

## Numbered Findings List

### Group 1: Hard Gate (Priority: HIGH)

#### [01] R-02 — Em Dash Character di Teks UI
- **Lokasi:** `src/components/ProgramViewerModal.jsx:876`
- **Kode:** `{program.sheetName} — {monthLabel || 'Agustus 2026'}`
- **Alasan:** Aturan R-02 melarang keras karakter em dash (`—`) pada teks UI; harus diganti pemisah natural seperti `·`, `:`, atau kurung `({monthLabel})`.
- **Rekomendasi:** Ubah menjadi `{program.sheetName} · {monthLabel || 'Agustus 2026'}`.

#### [02] R-17 & R-38 — Fallback Angka Rekayasa pada Notifikasi & KPI
- **Lokasi:** 
  - `src/routes/AppLayout.jsx:95` (`return count > 0 ? count : 1`)
  - `src/components/layout/TopHeaderBar.jsx:14` (`pendingCount = 1`)
  - `src/components/dashboard/AnalyticsBarChartCard.jsx:20` (`safeKpi.actPending || 1`)
  - `src/components/Dashboard.jsx:41` (`actBelum: 9029`)
  - `src/components/dashboard/AnalyticsBarChartCard.jsx:22` (`safeKpi.actBelum || 9029`)
- **Alasan:** Memaksa fallback angka `1` pada notifikasi saat data 0 atau belum ada menciptakan badge rekayasa; hardcode `9029` saat data kosong melanggar kejujuran data (R-17 & R-38).
- **Rekomendasi:** Tampilkan `0` atau hilangkan badge jika count adalah 0. Ganti fallback `9029` menjadi `0`.

#### [03] R-17 & R-27 — Mock Branch Fallback saat Data Kosong
- **Lokasi:** 
  - `src/components/dashboard/AnalyticsBarChartCard.jsx:27-34`
  - `src/components/dashboard/RightWidgetPanel.jsx:118-125`
- **Alasan:** Menyematkan data hardcoded mock branch (`Purwokerto 10.4%`, `Pekalongan 10.6%`, dst.) saat `ranking` kosong melanggar prinsip Empty State (R-27) dan Data & Numbers (R-17).
- **Rekomendasi:** Hapus mock fallback. Tampilkan empty state yang rapi ("Belum ada data monitoring") jika `ranking.length === 0`.

#### [04] R-32 — Penghapusan Focus Outline Tanpa Pengganti (`outline: none`)
- **Lokasi:**
  - `src/index.css:75, 89` (`button { outline: none; }`, `select, input { outline: none; }`)
  - `src/components/LandingPage.jsx:118`
  - `src/components/dashboard/SearchFilterToolbar.jsx:45, 93`
  - `src/components/UploadModal.jsx:151, 172, 192, 213`
  - `src/components/CekPairingPopover.jsx:230`
  - `src/components/Auth/LoginPage.jsx:166, 236, 275, 300, 359`
  - `src/components/ProjectTable.jsx:410`
  - `src/components/admin/MonitoringTab.jsx:142`
- **Alasan:** Menghilangkan focus outline bawaan tanpa menyediakan `:focus-visible` ring membuat pengguna keyboard (Tab) kehilangan penanda posisi aktif.
- **Rekomendasi:** Sediakan indikator fokus terpadu di `src/index.css` (`:focus-visible { outline: 2px solid #C8102E; outline-offset: 2px; }`).

#### [05] R-32 — Modal & Popover Tidak Mendukung Penutupan via Tombol `Escape`
- **Lokasi:**
  - `src/components/ReviewModal.jsx`
  - `src/components/UploadModal.jsx`
  - `src/components/ConfirmDeleteModal.jsx`
  - `src/components/ConfirmRejectModal.jsx`
  - `src/components/ConfirmSubmitModal.jsx`
  - `src/components/CekPairingPopover.jsx`
  - `src/components/layout/LogoutConfirmModal.jsx`
  - `src/components/layout/SessionExpiredModal.jsx`
  - `src/components/admin/DeleteProgramConfirmModal.jsx`
  - `src/components/admin/ExportRekapModal.jsx`
  - `src/components/admin/UploadGuideModal.jsx`
- **Alasan:** R-32 mewajibkan setiap modal/dialog dapat ditutup menggunakan tombol `Escape` untuk kepatuhan navigasi keyboard.
- **Rekomendasi:** Tambahkan `useEffect` event listener keyboard `Escape` pada modal-modal tersebut.

#### [06] R-39 — Elemen Interaktif Menggunakan Clickable `<div>` / `<span>`
- **Lokasi:**
  - `src/components/ProjectTable.jsx:66-95` (chevron & baris proyek menggunakan `div onClick`)
  - `src/components/ProjectTable.jsx:487-502` (tombol filter kolom menggunakan `div onClick`)
  - `src/components/UploadView.jsx:189, 204` (dropdown capsule & dropdown items menggunakan `div onClick`)
  - `src/components/ReviewModal.jsx:226-235` (thumbnail foto bukti menggunakan `div onClick`)
  - `src/components/dashboard/RightWidgetPanel.jsx:10` (mini card branch item)
- **Alasan:** Aksi pengguna wajib menggunakan elemen `<button>` atau setidaknya dilengkapi `role="button"`, `tabIndex="0"`, dan handler `Enter`/`Space`.
- **Rekomendasi:** Ubah elemen tersebut menjadi `<button type="button">` atau tambahkan atribut aksesibilitas semantik.

#### [07] R-39 — CSS Base Layer Belum Menetapkan Pointer & Disabled State Global
- **Lokasi:** `src/index.css:87-90`
- **Alasan:** R-39 mewajibkan seluruh kontrol aktif menampilkan `cursor: pointer` melalui base CSS, dan kontrol non-aktif menampilkan `cursor: not-allowed`.
- **Rekomendasi:** Tambahkan pada base layer `button, a[href], select, summary, label[for] { cursor: pointer; }` dan `:disabled { cursor: not-allowed !important; }`.

#### [08] R-39 — Tombol Ikonik Tanpa Accessible Name (`aria-label`) & Form Tanpa Label Terhubung
- **Lokasi:**
  - `src/components/layout/TopHeaderBar.jsx:80` (Tombol cepat `+`)
  - `src/components/layout/TopHeaderBar.jsx:179` (Tombol lonceng notifikasi)
  - `src/components/ReviewModal.jsx:148` (Tombol tutup `✕`)
  - `src/components/UploadModal.jsx:111` (Tombol tutup `✕`)
  - `src/components/CekPairingPopover.jsx:190` (Tombol tutup `✕`)
  - `src/components/dashboard/SearchFilterToolbar.jsx:32, 80, 100` (Dropdown scope & input pencarian)
  - `src/components/UploadModal.jsx:144` (Input form tanpa keterhubungan `id` ke `htmlFor`)
- **Alasan:** Pembaca layar (screen reader) tidak dapat mengidentifikasi fungsi tombol icon-only tanpa teks atau `aria-label`.
- **Rekomendasi:** Berikan `aria-label` deskriptif pada semua tombol icon-only dan hubungkan `<label htmlFor="...">` dengan `<input id="...">`.

#### [09] R-25 — Kontras Warna Rendah (Teks Abu-Abu Terang di Atas Latar Putih)
- **Lokasi:**
  - `src/components/BranchView.jsx:133, 143, 155` (Warna `#94A3B8` di atas latar `#FFFFFF`)
  - `src/components/ReviewModal.jsx:155, 159, 163, 167, 215` (Warna `#94A3B8` di atas `#F8FAFC`)
  - `src/components/dashboard/RightWidgetPanel.jsx:40` (`#94A3B8` untuk nomor peringkat)
- **Alasan:** Rasio kontras `#94A3B8` pada background putih hanya ~2.5:1, gagal memenuhi standar WCAG AA (minimum 4.5:1 untuk teks normal).
- **Rekomendasi:** Naikkan kontras teks sekunder minimal ke `#64748B` (rasio 4.6:1) atau `#475569` (rasio 7.0:1).

#### [10] R-03 — Viewport Height Clipping & Ukuran Minimum Tap Target Mobile
- **Lokasi:**
  - `src/components/LandingPage.jsx:20-21` (`height: '100vh', overflow: 'hidden'`)
  - `src/components/layout/TopHeaderBar.jsx:87, 184` (Tombol 38x38px)
- **Alasan:** `100vh` rentan terpotong oleh address bar peramban mobile; tombol 38px di bawah standar tap target mobile 44px (R-03).
- **Rekomendasi:** Gunakan `minHeight: '100dvh'` pada Landing Page, serta pastikan area sentuh tombol header memiliki hit area minimal 44px.

### Group 2: Purpose-Gate (Priority: MEDIUM)

#### [11] R-01 & R-13 — Efek Animasi Glowing Shadow AI Slop
- **Lokasi:** `src/index.css:37-50` (`@keyframes portalPulse`)
- **Alasan:** `@keyframes portalPulse` menggunakan `box-shadow` berlapis neon hingga 120px (`0 0 120px rgba(200, 16, 46, 0.4)`), pola visual AI slop tanpa tujuan fungsional.
- **Rekomendasi:** Bersihkan atau sesuaikan animasi agar tenang dan profesional sesuai palet Telkomsel.

#### [12] R-10 — Glassmorphism Bertumpuk (Overuse of Blur)
- **Lokasi:** 
  - `src/components/layout/TopHeaderBar.jsx:50` (`backdropFilter: 'blur(8px)'`)
  - `src/components/layout/AppSidebar.jsx:78` (`backdropFilter: 'blur(4px)'`)
  - `src/components/ReviewModal.jsx:141` (`backdropFilter: 'blur(4px)'`)
  - `src/components/ConfirmDeleteModal.jsx:18` (`backdropFilter: 'blur(8px)'`)
- **Alasan:** Penggunaan backdrop blur di hampir seluruh layer (header, modal, backdrop, sidebar) memperberat performa rendering perangkat rendah tanpa alasan hierarki yang kuat.
- **Rekomendasi:** Batasi blur hanya pada overlay backdrop modal utama, gunakan background solid opasitas tinggi pada header.

#### [13] R-39 & R-19 — Animasi Transisi Belum Diproteksi `prefers-reduced-motion`
- **Lokasi:** `src/index.css:52-62, 109-117, 204-213`
- **Alasan:** Animasi `floatAnim`, `rotateRing`, `flyoutSlideDown`, `fadeIn`, dan transisi card hover belum tercakup dalam kueri `@media (prefers-reduced-motion: reduce)`.
- **Rekomendasi:** Perluas cakupan `@media (prefers-reduced-motion: reduce)` di `index.css` agar mematikan atau menyederhanakan seluruh animasi saat user mengaktifkan pengaturan hemat gerak.

### Group 3: Quality Locks (Priority: LOW)

#### [14] R-11 — Penggunaan Border-Radius Pill Ekstrem (`50px`) yang Berlebihan
- **Lokasi:**
  - `src/components/BranchView.jsx:110, 182`
  - `src/components/UploadView.jsx:241`
  - `src/components/CekPairingPopover.jsx:273`
  - `src/components/admin/MonitoringTab.jsx:142`
  - `src/components/ProjectTable.jsx:410`
  - `src/index.css:503, 623, 640`
- **Alasan:** Membuat seluruh tombol aksi, kapsul filter, dan input menjadi bentuk kapsul/pill bulat penuh (`borderRadius: 50px`) adalah tanda visual khas template AI generic.
- **Rekomendasi:** Terapkan skala radius desain modern yang seragam: `8px` (kecil), `10px` (kontrol/input), `12px` (tombol), `16px` (kartu/kontainer).

#### [15] R-04 & R-16 — Karakter Emoji dalam Teks Placeholder Input
- **Lokasi:** `src/components/BranchView.jsx:202` (`placeholder="🔍 Cari proyek / WOK / ODP di branch..."`)
- **Alasan:** Menggunakan emoji kaca pembesar `🔍` langsung di dalam string placeholder input merupakan kebiasaan AI template; placeholder sebaiknya berupa teks profesional dan icon ditampilkan via SVG terpisah.
- **Rekomendasi:** Bersihkan placeholder menjadi `"Cari proyek, WOK, atau ODP..."`.

#### [16] R-06 — Inkonsistensi Deklarasi Font Family Antara 'Outfit' dan 'Plus Jakarta Sans'
- **Lokasi:** `src/components/BranchView.jsx:118, 130`, `src/components/UploadView.jsx:120, 140`, `src/components/CekPairingPopover.jsx:185`, `src/components/UploadModal.jsx:104`
- **Alasan:** Font heading didefinisikan sebagai `'Plus Jakarta Sans'` di root `index.css`, namun beberapa komponen secara sporadis menyuntikkan inline `fontFamily: "'Outfit', sans-serif"` tanpa sistem token yang terpusat.
- **Rekomendasi:** Standarkan penggunaan variabel CSS token (`var(--font-heading)` dan `var(--font-body)`) agar tipografi kohesif di seluruh aplikasi.
