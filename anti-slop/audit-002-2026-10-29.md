## Executive Summary
Audit mendalam dilakukan terhadap seluruh berkas dan komponen yang membangun halaman **Activity & Pelaporan Lapangan** (`/upload`). Audit menguji setiap komponen visual, layout tabel virtual, kontrol dropdown/filter, modal form upload, modal verifikasi admin, dialog konfirmasi, dan copywriting terhadap standar anti-slop.

Ditemukan **13 temuan** yang dikelompokkan berdasarkan tingkatan aturan:
- **7 Temuan HIGH (Hard Gate)**: Pelanggaran absolut yang memengaruhi aksesibilitas keyboard (Escape & click-outside pada popover/dropdown, focus trapping pada modal), semantik HTML (clickable `div`), integritas tipografi metrik (`tabular-nums`), kontras warna (WCAG AA), dan kalkulasi warna HSL pelangi.
- **2 Temuan MEDIUM (Purpose-Gate)**: Penggunaan gradien diagonal 135deg generik pada tombol aksi serta pemakaian grafis backdrop-blur berlebih pada seluruh modal overlay.
- **4 Temuan LOW (Quality Locks)**: Inkonsistensi radius pill ekstrem `50px` pada pagination, empty state pasif tanpa tombol pemulihan, emoji dalam teks tautan, dan inkonsistensi variabel font token heading.

## Numbered Findings List

### Group 1: Hard Gate (Priority: HIGH)

#### [01] R-18 & R-37 — Kalkulasi HSL Dinamis Pelangi Tanpa Tujuan Desain
- **Lokasi:** `gtm-monitor-frontend/src/components/UploadView.jsx:93-106, 141, 174`
- **Kode:**
  ```javascript
  const getDynamicColor35 = (val) => {
    const numeric = parseFloat(val) || 0;
    const ratio = Math.min(Math.max(numeric / 35, 0), 1);
    const hue = Math.round(ratio * 140); // 0 (Red) -> 140 (Green)
    return `hsl(${hue}, 85%, 40%)`;
  };
  ```
- **Alasan:** Interpolasi hue HSL 0 hingga 140 secara linier menghasilkan warna zaitun/kuning kehijauan keruh (*muddy rainbow*) di rentang nilai tengah. Ini melanggar prinsip warna dengan tujuan (R-18) dan merusak konsistensi palet korporat Telkomsel.
- **Rekomendasi:** Gunakan status token diskret terkalibrasi (misal: `< 35%` `#DC2626`, `35-70%` `#D97706`, `≥ 70%` `#16A34A`) atau warna semantik korporat yang stabil.

#### [02] R-17 — Metrik Data Numerik Tanpa Tabular Figures (`tabular-nums`)
- **Lokasi:**
  - `src/components/UploadView.jsx:140, 157, 174` (Port Avai/Used/Total, Proyek/ODP, Pct Selesai)
  - `src/components/ProjectTable.jsx:42-44, 101-103, 704` (Kolom Used, Avai, Total, dan Pagination counter)
  - `src/components/ReviewModal.jsx:184, 188, 192, 196` (Modal KPI counters)
- **Alasan:** R-17 mewajibkan angka numerik pada data tabular dan kartu statistik menggunakan `font-variant-numeric: tabular-nums`. Tanpa properti ini, angka dengan lebar karakter variabel menimbulkan jitter visual dan ketidaksejajaran saat data diperbarui.
- **Rekomendasi:** Tambahkan kelas `tabular-nums` atau inline style `fontVariantNumeric: 'tabular-nums'` pada seluruh representasi angka metrik.

#### [03] R-39 — Elemen Interaktif Menggunakan Clickable `<div>` Tanpa Semantik Tombol & Keyboard Access
- **Lokasi:**
  - `src/components/ProjectTable.jsx:89-98` (Nama proyek & WOK expand toggle)
  - `src/components/ProjectTable.jsx:393-405` (Opsi sort A-Z dan Z-A pada popup filter kolom)
  - `src/components/ProjectTable.jsx:663-671` (Pilihan page size dalam popup pagination)
- **Alasan:** Penggunaan `div onClick` tanpa `role="button"`, tanpa `tabIndex="0"`, dan tanpa handler tombol `Enter`/`Space` membuat kontrol tidak dapat dioperasikan oleh pengguna navigasi keyboard.
- **Rekomendasi:** Ubah elemen tersebut menjadi `<button type="button">` atau lengkapi dengan `role="button"`, `tabIndex={0}`, dan event listener keyboard.

#### [04] R-32 — Dropdown & Popover Tidak Mendukung Penutupan via Tombol `Escape` & Click-Outside
- **Lokasi:**
  - `src/components/UploadView.jsx:187-233` (Dropdown filter branch tidak memiliki listener Escape maupun click-outside)
  - `src/components/ProjectTable.jsx:623-674` (Dropdown page size tidak memiliki listener Escape maupun click-outside)
  - `src/components/ProjectTable.jsx:369-475` (Popover filter kolom tidak memiliki listener Escape)
- **Alasan:** R-32 mewajibkan setiap menu popup, popover, dan dropdown dapat ditutup secara instan menggunakan tombol `Escape` dan saat pengguna mengklik area luar menu (*click-outside*).
- **Rekomendasi:** Pasang event listener `Escape` dan hook `click-outside` terpadu pada ketiga kontrol popover/dropdown tersebut.

#### [05] R-32 & R-39 — Modal Dialog Belum Dilengkapi Focus Trap (Focus Leaking ke Background)
- **Lokasi:**
  - `src/components/UploadModal.jsx`
  - `src/components/ReviewModal.jsx`
  - `src/components/ConfirmSubmitModal.jsx`
  - `src/components/ConfirmDeleteModal.jsx`
  - `src/components/ConfirmRejectModal.jsx`
- **Alasan:** Ketika modal aktif (`aria-modal="true"`), menekan tombol `Tab` dapat memindahkan fokus keyboard keluar dari dialog menuju elemen-elemen di halaman latar belakang yang tertutup backdrop.
- **Rekomendasi:** Terapkan pembatasan fokus (focus trap) di dalam kontainer modal saat dialog berstatus terbuka.

#### [06] R-25 — Kontras Warna Teks & Badge Rendah (Gagal WCAG AA 4.5:1)
- **Lokasi:**
  - `src/components/ProjectTable.jsx:559` (Teks empty state menggunakan `#94a3b8`, rasio ~2.5:1 di atas putih)
  - `src/components/ReviewModal.jsx:243` (Teks "Belum ada data/foto kegiatan" menggunakan `#94a3b8`)
  - `src/components/ProjectTable.jsx:23` (Badge amber teks `#d97706` di atas latar `#fef3c7`, rasio ~3.8:1)
- **Alasan:** Rasio kontras teks sekunder dan badge di bawah standar WCAG 2.1 AA (minimum 4.5:1 untuk teks biasa).
- **Rekomendasi:** Tingkatkan warna teks sekunder minimal ke `#64748B` (4.6:1) atau `#475569` (7:1); ubah teks badge amber menjadi `#B45309` (5.1:1).

#### [07] R-39 — Accessible Name Tombol Pratinjau, Asosiasi Label Input File, dan Tap Target Review
- **Lokasi:**
  - `src/components/UploadModal.jsx:242, 279-284` (Input file tanpa `id` dan tidak terhubung ke `<label htmlFor="...">`)
  - `src/components/ReviewModal.jsx:418-422` (Tombol silang tutup pratinjau lightbox tanpa `type="button"` dan tanpa `aria-label`)
  - `src/components/ProjectTable.jsx:184-189` (Tombol Review tanpa `type="button"` dan tinggi tap target < 44px)
- **Alasan:** Elemen interaktif harus memiliki nama yang dapat dibaca screen reader, input file wajib terhubung semantik ke labelnya, dan tombol aksi harus memiliki hit area minimal 44px (R-03 / R-39).
- **Rekomendasi:** Tambahkan atribut `id`/`htmlFor`, pasang `aria-label`, serta berikan `type="button"` dan padding yang nyaman pada tombol Review.

### Group 2: Purpose-Gate (Priority: MEDIUM)

#### [08] R-36 — Gradien Diagonal 135deg Mencolok pada Seluruh Tombol Aksi & Badge
- **Lokasi:**
  - `src/components/ProjectTable.jsx:132, 151, 165` (`linear-gradient(135deg, ...)` pada tombol Cek Status, Tambah Foto, Upload)
  - `src/components/UploadModal.jsx:307` (`linear-gradient(135deg, #FF5E00 0%, #C8102E 100%)`)
  - `src/components/ConfirmSubmitModal.jsx:83` (`linear-gradient(135deg, #FF5E00 0%, #C8102E 100%)`)
  - `src/components/ConfirmDeleteModal.jsx:183` (`linear-gradient(135deg, #E11D48 0%, #BE123C 100%)`)
  - `src/components/ConfirmRejectModal.jsx:182` (`linear-gradient(135deg, #EF4444 0%, #DC2626 100%)`)
- **Alasan:** Penumpukan gradien diagonal 135deg mencolok di setiap tombol merupakan ciri khas AI slop generic, mengaburkan hierarki visual dan bertabrakan dengan palet korporat Telkomsel.
- **Rekomendasi:** Ubah background tombol menjadi warna solid bersih (`#C8102E` untuk primary, `#16A34A` untuk upload foto sukses, `#D97706` untuk cek status) dengan hover elevation terukur.

#### [09] R-10 — Overuse Backdrop Filter Blur pada Seluruh Modal Dialog
- **Lokasi:**
  - `src/components/UploadModal.jsx:99` (`backdropFilter: 'blur(8px)'`)
  - `src/components/ConfirmSubmitModal.jsx:27` (`backdropFilter: 'blur(8px)'`)
  - `src/components/ConfirmDeleteModal.jsx:33` (`backdropFilter: 'blur(8px)'`)
  - `src/components/ConfirmRejectModal.jsx:34` (`backdropFilter: 'blur(8px)'`)
  - `src/components/ReviewModal.jsx:161` (`backdropFilter: 'blur(4px)'`)
- **Alasan:** Penggunaan backdrop blur berat pada setiap modal fixed overlay membebani GPU perangkat berspesifikasi rendah tanpa alasan hierarki desain yang esensial.
- **Rekomendasi:** Hapus backdrop blur berlebih atau sesuaikan ke tingkat sangat halus (`blur(2px)`), gunakan latar overlay gelap solid semi-transparan `rgba(15, 23, 42, 0.6)`.

### Group 3: Quality Locks (Priority: LOW)

#### [10] R-11 — Inkonsistensi Border Radius Pill Ekstrem (`50px`) pada Kontrol Pagination
- **Lokasi:** `src/components/ProjectTable.jsx:629, 686, 714`
- **Kode:** `borderRadius: '50px'` pada tombol page size dan tombol panah navigasi prev/next.
- **Alasan:** Menggunakan radius kapsul `50px` yang terisolasi pada footer tabel merusak konsistensi skala radius antarmuka (skala terpadu `8px` - `12px`).
- **Rekomendasi:** Standarkan border radius pagination ke `10px` / `12px`.

#### [11] R-27 — Empty State Pasif Tanpa Tombol Aksi Pemulihan (Reset Filters)
- **Lokasi:**
  - `src/components/UploadView.jsx:317-329` (Kondisi hasil pencarian proyek kosong)
  - `src/components/ProjectTable.jsx:558-562` (Kondisi filter kolom mengosongkan baris tabel)
- **Alasan:** Kontainer empty state hanya berupa teks peringatan pasif tanpa tombol pemulihan langsung untuk mereset kata kunci atau menghapus filter kolom aktif.
- **Rekomendasi:** Tambahkan ikon visual dan tombol aksi "Reset Pencarian" / "Bersihkan Filter".

#### [12] R-04 & R-16 — Karakter Emoji & Kosakata Jargon Campuran pada Copywriting Modal
- **Lokasi:**
  - `src/components/ReviewModal.jsx:436` (`🔗 Buka Foto Ukuran Asli di Tab Baru`)
  - `src/components/ConfirmSubmitModal.jsx:59` (`"...pada proyek/lop \"{projectName}\"?"`)
- **Alasan:** Menempatkan karakter emoji `🔗` langsung di dalam teks tautan adalah kebiasaan AI template; istilah `"proyek/lop"` menggunakan garis miring redundan yang kurang baku.
- **Rekomendasi:** Ganti emoji `🔗` dengan ikon SVG tautan eksternal; rapikan teks konfirmasi menjadi `"pada proyek {projectName}"`.

#### [13] R-06 — Inkonsistensi Deklarasi Font Heading pada Modal Review
- **Lokasi:** `src/components/ReviewModal.jsx:166`
- **Alasan:** Elemen judul utama `#review-modal-title` tidak menerapkan variabel token font heading `var(--font-heading)` seperti modal-modal lainnya.
- **Rekomendasi:** Terapkan `fontFamily: "var(--font-heading)"` pada elemen judul `#review-modal-title`.
